# Mobil Uygulamalar - GitHub ile derleme

Öğrencinin düzenleyeceği tek dosya:
`app/src/main/res/layout/activity_main.xml`

Hazır kitap örnekleri `ornekler/` klasöründedir. İstediğiniz örneğin içeriğini kopyalayıp `activity_main.xml` içine yapıştırın.

Derleme: Actions sekmesi > "APK Derle" > en alttaki Artifacts bölümünden `app-debug-apk` indirilir.
Ekran görüntüsü: Actions sekmesi > "Emulatorde Calistir..." > Run workflow > bitince `ekran-goruntusu` indirilir.

Java kodu gereken örnekler (java_metot, onayla) `MainActivity.java` içinde hazırdır.
